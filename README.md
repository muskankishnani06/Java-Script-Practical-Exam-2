# JavaScript Condition with Looping Programs

This repository contains JavaScript programs based on **conditions, loops, and nested loops**.

Video link :- https://drive.google.com/file/d/1iDHpVy2zYRXLDsBMP_FlfZzxvaU9-8wE/view?usp=drive_link

## 📚 Programs

| No. | Program                                                 | Description                                                     |
| --- | ------------------------------------------------------- | --------------------------------------------------------------- |
| 21  | [Multiplication Table](https://codepen.io/muskankishnani06/pen/azJdvdE)       | Print the multiplication table of a number from 1 to 10         |
| 22  | [Sum of Even Numbers](https://codepen.io/muskankishnani06/pen/PwpZPZr)         | Find the sum of all even numbers from 1 to N                    |
| 23  | [Count Positive Negative](https://codepen.io/muskankishnani06/pen/pvegjyE) | Count positive numbers, negative numbers, and zeros in an array |
| 24  | [Fibonacci Series](https://codepen.io/muskankishnani06/pen/azJdvZq)               | Print the Fibonacci series up to N terms                        |
| 25  | [Number Pattern](https://codepen.io/muskankishnani06/pen/ogZbjLP)                   | Print a number pattern using nested loops                       |
